# 🎵 Jewish Music Downloader

A Python CLI app to search, browse, and download music from jewishmusic.fm.

## Features
- 🔍 Search by artist, album, or song name
- 🔥 Browse new releases
- ⭐ Favorites system
- 📋 Playlists
- ▶️ Built-in audio player
- 👥 Multi-account support
- 👑 Admin panel with Firebase user management
- 📊 Download statistics & history
- 📥 Progress bar downloads

## Install (Pydroid 3 on Android)

1. Install **Pydroid 3** from Google Play
2. Open Pydroid 3 → ☰ → Pip → Install `requests`
3. Optional: Install `firebase-admin` for user management
4. Open `jewish_music_downloader.py` → Press ▶️

## Usage
Type a singer name to search, or use menu commands:
- `s` — Search (artist/album/song)
- `new` — New releases
- `fav` — Favorites
- `pl` — Playlists
- `play` — Play downloaded songs
- `admin` — Admin panel
- `stats` — Statistics
